Capability statement

Joseph Thompson, owner

Thompson SWE LLC is a veteran-owned software engineering firm in Atlanta, Georgia. One engineer builds integrations, platform extensions, and data pipelines for supply chain planning systems, and delivers web applications and machine learning work on the same terms.

Core capabilities

  • Systems integration. Inbound and outbound data feeds between planning systems, ERPs, and in-house platforms, over REST APIs, Google Cloud Pub/Sub, and RabbitMQ.
  • Platform extensions. Custom logic on enterprise supply chain planning platforms: technical design, development, documentation, and production support.
  • Data conversion and reconciliation. Legacy-to-cloud migration, Airflow pipelines, and multi-million-row comparisons with Python, Oracle, pandas, and DuckDB.
  • Web applications. React front ends, API back ends, sign-in, and cloud hosting.
  • Machine learning. Forecasting and classification with Python and PyTorch.

Experience of the owner

  • Technical lead for a 24-extension program for a national pharmaceutical distributor on a cloud forecasting and replenishment platform. Wrote 17 technical designs, built 6 extensions, and was responsible for all inbound and outbound integration.
  • Built a purchase order enrichment service covering about 80,000 items and 60,000 sourcing relationships, and a rule that separates controlled-substance lines onto their own purchase orders to meet DEA requirements.
  • Built legacy-to-cloud data conversion and multi-million-row comparison tooling reused across client implementations.

Enterprise projects were delivered on a software vendor's implementation team, not under the Thompson SWE name. Client names are withheld.

Tools

Python, SQL (Oracle, MySQL), JavaScript, React, Airflow, pandas, NumPy, DuckDB, Parquet, PyTorch, REST APIs, Google Cloud Pub/Sub, RabbitMQ, AWS Amplify, Git

Why Thompson SWE

  • One named engineer does the work. No handoffs and no bench.
  • Enterprise supply chain planning experience together with general software engineering.
  • Every deliverable comes with a technical design and documentation.
  • Veteran-owned. The owner led a 12-Marine team in the U.S. Marine Corps.
